# ToneDeaf - Joysound 風格人聲旋律音高分析與練唱系統

一個專為歌唱愛好者與音樂人打造的高精度旋律抓取、音程提示與練唱輔助工具。

---

## 🌟 核心特色

1. **AI 純人聲分離（Meta Demucs v4）**：
   - 自動將伴奏與人聲乾淨分離，消除樂器重疊泛音對音準分析的干擾。
2. **高精度神經網路音高追蹤（TorchCREPE 滿載版）**：
   - 採用深度卷積網路抓取物理基頻（F0），時間解析度 10ms，音高精度達 32 cents。
   - 結合 RMS 分貝能量閥門，智慧過濾空拍背景雜音與微弱呼吸噪訊。
3. **日本 Joysound / DAM 風格「音程バー」橫向滾動捲軸**：
   - **防殘影黑曜高對比徽章**：每個音符條強制標註「超大簡譜數字 + 英文音名代號」（如 `5̇ G4`、`1 C4`），外加高對比底標，高速滑動邊緣依然銳利不模糊。
   - **固定判定線靜止標靶 HUD**：視線輕鬆停留在左側判定線上，開唱與倒數即時提示，徹底告別追著音符跑的眼睛疲勞。
   - **視野速度調節**：預設超平緩抗殘影視野（8 秒 / 10 秒 / 6 秒 / 4 秒）。
4. **鋼琴捲軸直接拖曳時間軸（物理捲軸手感）**：
   - **往左拉 ＝ 往後快轉 ⏩**（時間增加）
   - **往右拉 ＝ 往前倒帶 ⏪**（時間減少）
   - 拖曳時即時顯示秒數差浮層提示，**放開滑鼠立即接續播放**！
5. **暫存播放起點（練唱循環錨點）**：
   - 支援將特定秒數（例如副歌前置音）記為固定起點。
   - 鋼琴捲軸上即時標記綠色地標旗標（`📌 起點 00:23.5`）。
   - 支援一鍵回到起點（`⏮ 跳至起點`）與重設（`🔄 設回 0 秒`），與自由左右拖曳拉時間完全互不衝突。
6. **練唱輔助工具**：
   - 支援全音域半音移調即時換算（1 = C, 1 = D 等即時簡譜對應）。
   - 0.75x ~ 1.5x 慢速與原速練習。
   - 藍牙耳機微秒延遲校準補償。

## 🚀 快速上手

### 1. 環境安裝
```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt  # 或安裝 torch, torchcrepe, demucs, librosa, numpy, scipy
```

### 2. 執行分析
直接傳入音檔（若尚未分離人聲會自動調用 Demucs 抽離人聲）：
```bash
./.venv/bin/python analyze_lyrics_pitch.py test.mp3
```
分析完成後，音高資料將儲存於 `output/<track>_pitch.json`。

### 3. 開啟網頁播放器
```bash
./.venv/bin/python web_editor.py
```
在瀏覽器打開：`http://localhost:8765`

* **快捷操作提示**：
  * **空白鍵（Space）**：播放 / 暫停
  * **← / → 鍵**：倒帶 / 快轉 3 秒
  * **滑鼠在捲軸上按住拖曳**：往左拉快轉、往右拉倒帶，放開自動繼續播放！
  * **點擊任意音符**：瞬間跳轉至該音符開唱！
